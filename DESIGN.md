# NumenX Design System

Direction: Liquid Chrome. A raymarched chrome chip on near-black, one cyan accent.

## Color
- Ink #050609, Ink 2 #0a0c11, Ink 3 #10131a
- Silver #e9edf5, Steel #8b95a7
- Accent cyan #5fd4ff (only accent; no violet, no orange)

## Type
- Display: Anybody, variable width 50-150 and weight 100-900
- Body and labels: Instrument Sans
- No monospace. Headings use Title Case and run two lines or fewer.

## Components
- Buttons: flat, no resting glow. Primary is solid cyan, ghost is outlined. Magnetic on hover (fine pointers only).
- Header: solid, no blur.
- Section rhythm: 64-120px padding. Tonal wave dividers between sections, plus a light grain overlay.
- Motion: staged once-only reveals, scroll progress bar, row spotlight, hero tagline scramble. All respect prefers-reduced-motion.
- Command palette: Ctrl/Cmd+K.
